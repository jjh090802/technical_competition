# 2021 무형문화재관리원 화면 캡처

프로젝트를 실제로 실행하며 찍은 화면이다 (2026-10-01 기준). 1920px 은 문서 전체를 한 장으로, 모달은 화면(1920×1080) 크기로 찍었다.
A·B·C 모두 애니메이션이 한창일 때 찍히지 않도록 같은 시각에 멈추거나 끈 사본으로 찍었다. 마우스를 올린 상태는 같은 스타일을 CSS 로 강제해 찍었다.
이 과제에는 로그인·역할 구분이 없어 C 는 한 가지 역할(누구나 관리)로 찍었다. alert·confirm 창은 캡처되지 않아 표의 '메시지' 칸에 문구를 적었다.
갤러리: `index.html` 을 브라우저로 연다.
