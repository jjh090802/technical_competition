# 화면 캡처 (2020 지방 내집꾸미기)

프로젝트를 실제로 띄워 놓고 크롬(헤드리스, DevTools 프로토콜)으로 찍었다. 창 폭은 1600px 이고, A 의 모바일 화면만 480px 이다.
세로로 긴 페이지는 전체를 한 장으로, 모달은 화면(1600×900) 크기로 찍었다. 마우스 오버 화면은 실제 마우스를 올려서 찍었다.
경고창(alert)은 이미지에 나오지 않으므로 그 문구를 표의 "메시지" 칸에 적었다. 갤러리는 `index.html` 을 더블클릭해서 본다.

## 띄운 방법

- A: `A_Module/Publishing/index.html` 을 그대로 연다.
- B: `B_Module` 을 웹 서버로 연다 (XAMPP 라면 http://localhost/). 여기서는 `php -S 127.0.0.1:8820 -t B_Module`.
- C: `C_Module` 을 웹 서버 루트에 두고 `setup.php` 를 한 번 연 뒤, 사이트의 폼으로 아래 시연 데이터를 넣었다 (DB 를 직접 고치지 않았다).
